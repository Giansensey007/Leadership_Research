1. The 30-second one-liner

"I'm studying what firm-level factors predict women's representation in top leadership of S&P 500 companies. I scraped all 500 DEF 14A proxy filings from SEC EDGAR, extracted the Named Executive Officers (NEOs) from each company's Summary Compensation Table, and inferred gender using honorifics and first-name lookup. My dependent variable is the percentage of women among NEOs; my main IV is whether the CEO is female and which industry the firm is in."

3. Research question & hypotheses

RQ. What firm-level factors predict women's representation in top leadership (C-suite / NEOs) in S&P 500 companies?

H1. Board gender diversity (% women on board) is positively associated with the proportion of women in the C-suite.

H2. Firms with a female CEO or CFO have a higher proportion of women among NEOs overall.

H3. Industry moderates H1: the board→C-suite relationship is stronger in industries with historically low female representation (e.g., Energy, Industrials) — i.e., diverse boards matter more where there's more slack to fill.

Honest note: in the actual scraped data, you currently have NEOs + CEO gender, not board composition. If the prof asks about H1, say: "Board-level diversity is a planned extension; the pilot tests H2 (female CEO → more female NEOs) and the industry effect (H3 as a main-effect first)."

Key distinction to use out loud: "NEOs" (Named Executive Officers — the top 3–5 paid execs reported in the proxy) is what you actually measured. "C-suite" is the conceptual target. NEOs is the standard, auditable proxy for C-suite in accounting/finance research because firms are required by SEC rules to disclose it.

5. Research design

  • Type: Cross-sectional, observational, archival.
  • Unit of analysis: Firm (one row = one S&P 500 company).
  • Sample frame: Current S&P 500 constituents (snapshot from Wikipedia).
  • N: 500 firms targeted, 500 rows written, of which 340 have non-zero NEO data (the rest are parser misses, not missing filings).
  • Time window: Each firm's most recent DEF 14A (filings mostly 2024–2026).
  • Why DEF 14A: SEC-mandated annual proxy; legally required to list NEOs and compensation. No self-report bias.

6. Data & where it comes from

Source 1 — Wikipedia

Script: scripts/fetch_sp500_constituents.py

  • Fetches the S&P 500 list table.
  • Extracts ticker, company name, GICS sector.
  • Normalizes ticker class shares (BRK.B → BRK-B).
  • Writes data/sp500_constituents.csv (~503 rows).

Source 2 — SEC EDGAR

Script: scripts/collect_sec_data.py

  • Uses the edgartools Python library.
  • For each ticker: Company(ticker).get_filings(form="DEF 14A")[0] → latest proxy.
  • Pulls both the XBRL-parsed object and the rendered markdown of the filing.
  • SEC-friendly: sets an identity header and sleeps 2 s between tickers.
What is a DEF 14A? The definitive proxy statement US public firms must file before the annual meeting. It contains: board nominees, the Summary Compensation Table (SCT), Pay vs Performance, auditor ratification, etc. The SCT is where NEO names appear.

7. How the scraper actually works

Open scripts/collect_sec_data.py if asked. You need to be able to narrate these 5 steps:

Step 1 — Load tickers

load_companies() reads data/sp500_constituents.csv → list of (ticker, company, industry) tuples.

Step 2 — Fetch latest DEF 14A per ticker 
from edgar import Company, set_identity
set_identity("Leadership Research UZH research@uzh.ch")
filings = Company(ticker).get_filings(form="DEF 14A")
latest  = filings[0]
proxy   = latest.obj()     # structured (XBRL) view
md      = latest.markdown() # rendered markdown of filing body
Step 3 — Extract NEO names from the Summary Compensation Table

Function: extract_neos_from_compensation_table(md).

  • Scans the markdown for the phrase "Summary Compensation Table".
  • Walks forward until it finds a pipe-delimited header row that contains the word "salary".
  • Then reads each subsequent table row: if the first cell looks like a person's name (regex + capitalization rules) and dollar amounts ([\d,]{6,}) appear on that row or the next 3 lines, it's recorded as a NEO.
  • Handles two proxy styles: (A) name + salary same row (GM, META), (B) name one row, salary next row (AAPL, MSFT).
  • Fallback: if fewer than 2 NEOs found, try proxy.named_executives (XBRL attribute).
Step 4 — Build honorific lookup for the whole filing

Function: build_honorific_lookup(md).

Regex scans every line for Mr. Cook, Ms. Adams, Mrs. Smith. Returns two sets of lowercase last-names that the filing itself has already gendered. This is the single most reliable signal.

Step 5 — Assign gender + write CSV row

For each NEO, run the 3-tier cascade (next section). Aggregate counts, compute pct_female_neos, write row to leadership_gender_data.csv. Log failures to _failed_tickers.json so you can re-run only those with --retry-failed.

8. How gender is assigned (the 3-tier cascade)

Function: determine_gender(full_name, mr_set, ms_set).

  1. Tier 1 — Honorific in name itself. If the name literally starts with Mr., Ms., or Mrs. → decided.
  2. Tier 2 — Last-name lookup. Check the NEO's last name against the Mr./Ms./Mrs. sets harvested from the full filing. Example: filing says "Ms. Adams" somewhere else → any NEO with last name Adams is female.
  3. Tier 3 — First-name heuristic. Compare the cleaned first name against two curated sets (FEMALE_NAMES, MALE_NAMES) in the script. If no match → unknown, flagged for manual verification (not dropped).
If the prof pushes on gender inference validity: this is a known limitation. You're not asking people their gender; you're inferring from filings and names. That's standard in accounting/finance papers (e.g., Adams & Ferreira 2009 for boards, Xu 2023 for executive promotions). The honorific check is your strongest defense — it's the firm's own language, not your guess.

11. Analysis plan (what you'll do next in R)

  1. Descriptives + correlation matrix of numeric vars.
  2. OLS regression: pct_female_neos ~ female_ceo + industry + log_firm_size + controls.
  3. Interaction: add female_ceo × industry (or board_div × industry once board data is merged) to test H3.
  4. Assumption checks: linearity plots, residual normality (QQ), Breusch–Pagan for heteroskedasticity, VIF for multicollinearity (keep < 5).
  5. Robustness:
    • Replace DV with count of female NEOs (Poisson / negative binomial).
    • Drop firms with unknown_neos > 0.
    • Drop firms with total_neos < 3 (parser likely incomplete).
    • Subgroup analysis by industry.

12. Known caveats — own these before the prof raises them

Parser coverage Binary gender Cross-sectional Selection Unknown NEOs
  • Parser coverage. 160/500 firms returned 0 NEOs — that's a parser issue, not missing filings. Different proxy layouts, zero-width spaces (UNH), image-based PDFs, etc. Treat as a coverage caveat; re-run with an improved parser for final analysis.
  • Gender inference is binary + based on names. Doesn't capture non-binary identities; misclassifies ambiguous names. Honorific tier mitigates but doesn't eliminate.
  • Cross-sectional snapshot. One filing per firm → no causal claims, only associations.
  • Selection. S&P 500 = already large-cap, survivors. Results don't generalize to SMEs or private firms.
  • "Unknown" NEOs (15% of name-count) are preserved in data, not dropped. They bias pct_female_neos downward if truly female.
  • 3 failed tickers: BX (Blackstone), PSKY, Q — either symbol mismatch or atypical filings. Listed in _failed_tickers.json.

13. How the project evolved (the narrative)

  1. Proposal. Start with broader "women in leadership" question; originally planned N = 50 firms, manual collection, board + C-suite variables, industry moderator.
  2. Pilot (N = 50). Manual pull from corporate governance reports. Produced descriptives: mean board diversity 33%, mean C-suite diversity 18.2%, 8% female CEOs — already in the proposal.
  3. Scale-up. Replaced manual collection with the SEC EDGAR scraper. Switched from "C-suite" (hard to define consistently) to "NEOs" (legally-defined, standard in finance research, disclosed in every DEF 14A).
  4. Full S&P 500 pull. 500 rows produced. Parser hits 340/500, ~68% coverage.
  5. Now. Pilot-level analysis already possible on the scraped data (H2 and H3-as-main-effect). Board-composition data is the next extension.
If the prof says "this looks different from your proposal" — say: "Yes, I replaced manual collection with an automated SEC EDGAR pipeline and shifted the DV from self-defined C-suite to SEC-mandated NEOs to make the measure auditable and scalable to the full S&P 500."

14. Likely prof questions — have an answer ready

Q: "What's your dependent variable and why?"
Percent female among the firm's Named Executive Officers in the latest DEF 14A. NEOs is SEC-mandated disclosure (top 3–5 paid execs: CEO, CFO, next three), so it's the most consistent, auditable proxy for "top leadership" across 500 firms.
Q: "How do you know the gender is right?"
Three-tier cascade: honorific in the filing text (Mr./Ms./Mrs.) is primary — that's the firm's own language, not my guess. Fallback is first-name lookup. Remaining ~15% stays as 'unknown' for manual QA; I don't drop them silently.
Q: "Why do 160 firms have zero NEOs?"
Parser coverage, not missing filings. Each proxy has a unique layout; my parser handles two dominant formats (name+$ same row, name+$ split rows) and falls back to XBRL, but some filings (image PDFs, unusual table structures, embedded zero-width chars) still miss. A coverage caveat I'll address with parser improvements or manual QA on non-zero analytic subsample.
Q: "Why DEF 14A and not the 10-K?"
The DEF 14A is the definitive proxy statement — SEC Reg S-K Item 402 requires disclosure of NEO names and compensation there, not in the 10-K. So DEF 14A is the single canonical source.
Q: "Endogeneity? Female CEO firms may differ systematically."
Right — this is observational, associational, not causal. Female-CEO firms likely differ on industry, size, culture. I'll include GICS sector fixed effects and log firm size as controls, and I'm upfront that H2 is an association, not a treatment effect.
Q: "What's your N? Is it enough?"
500 firms pulled, 340 with non-zero NEO data. For a cross-sectional OLS with ~12 industries and one binary IV, that's comfortably powered — the bigger concern is coverage bias (non-random parser misses), which I'll check with sensitivity analysis.
Q: "How does this connect to existing literature?"
Eagly & Carli (2007) on individual-level barriers; Adams & Ferreira-type work on boards; Xu (2023) on executive promotions; the Catalyst (2024) descriptives. My contribution is a firm-level, publicly-verifiable pipeline across the full S&P 500, shifting focus from individual barriers to firm enablers.
Q: "What happens if a firm has no board-diversity data?"
Board variables are a planned extension; the pilot version of the paper uses only NEO gender and CEO gender (both derivable directly from the proxy). H1 becomes testable once I merge in board composition from the same DEF 14A's Director table.
Q: "What analysis will you actually run?"
OLS in R: pct_female_neos ~ female_ceo + factor(industry) + log_employees, then add female_ceo × industry. VIF, BP test, QQ plot. Robustness with count DV (Poisson), drop-unknown, drop-small-NEO.
